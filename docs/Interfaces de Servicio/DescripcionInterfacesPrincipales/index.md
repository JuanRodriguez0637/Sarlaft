# Descripción de Interfaces Principales

> **Fuente Confluence:** [Descripción de Interfaces Principales](https://segurosti.atlassian.net/wiki/spaces/EPA/pages/1955070150)  
> **Última modificación:** 2025-11-07 — Diana Muñoz · versión 18  
> **Sección:** [Interfaces de Servicio](../index.md)

Descripción de interfaces del servicio **Sarlaft 4.0** para comunicación con aplicativos de Suramericana.

Se documentan las siguientes interfaces:

- Validar Sarlaft (Proceso Síncrono)
- Almacenar Evidencias
- Consultar Formulario Sarlaft
- Interfaz Servicio WebHook (Finalización proceso de Sarlaft)
- Web Component
