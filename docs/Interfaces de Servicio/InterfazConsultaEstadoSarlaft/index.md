# Interfaz de Consulta de Estado Sarlaft

> **Fuente Confluence:** [Interfaz de Consulta de Estado Sarlaft](https://segurosti.atlassian.net/wiki/spaces/EPA/pages/1954644239)  
> **Última modificación:** 2021-05-05 — Diana Muñoz · versión 2  
> **Sección:** [Interfaces de Servicio](../index.md)

Interfaz expuesta para escenarios validados con el equipo base del proyecto Sarlaft 4.0, donde se debe recurrir a una consulta para conocer si el estado de Sarlaft ha sido finalizado, dado que su tecnología no puede implementar la comunicación por servicio REST para el patrón de webhook, o su flujo de negocio es más eficiente a través de esta consulta.

Caso especial para algunos cotizadores y `Policy Center`.
