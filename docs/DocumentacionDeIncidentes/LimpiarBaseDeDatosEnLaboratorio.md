## Requisitos previos

Antes de realizar el proceso, es necesario:

- **Acceso a la VPN** para conectarse a la base de datos.
- Tener la base de datos **configurada en un gestor** (normalmente se utiliza **DBeaver**).
- Contar con los permisos adecuados para ejecutar scripts en el entorno de laboratorio.

## Información sensible

Por motivos de seguridad, **no se muestran las tablas ni los scripts en esta documentación**.
Estos se entregarán en el **archivo correspondiente al líder responsable**, donde en el **punto número 1** se detallan las tablas y el script necesario para realizar el proceso.
