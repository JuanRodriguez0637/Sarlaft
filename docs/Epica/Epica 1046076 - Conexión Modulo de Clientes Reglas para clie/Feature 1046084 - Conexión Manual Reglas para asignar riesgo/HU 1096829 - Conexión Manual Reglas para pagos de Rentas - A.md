## Descripción

Yo como negocio de sarlaft Quiero: 
 **** **Ajuste en servicio de resultados de evaluación para incluir información de suboperación, recaudo y valor del pago**  
- Modificar el servicio /sarlaftbackweb/resultevaluation para que incluya en su respuesta la información de los siguientes campos: Tipo de suboperación, Tipo de recaudo y Valor del pago. 
- Se debe garantizar que estos campos sean retornados correctamente dentro de la estructura de respuesta del servicio, sin afectar la funcionalidad actual para los consumidores existentes.
