## Descripción

Yo como negocio de sarlaft Quiero: 
 **Ajustes al modelo, entidades y servicios para nuevos campos de suboperación, pagos y recaudos**

- Ajustar la entidad Póliza en base de datos para agregar los campos: Tipo de recaudo y Valor del pago 
- Modificar el servicio /assessment para que reciba los nuevos campos: Tipo de recaudo y Valor del pago
