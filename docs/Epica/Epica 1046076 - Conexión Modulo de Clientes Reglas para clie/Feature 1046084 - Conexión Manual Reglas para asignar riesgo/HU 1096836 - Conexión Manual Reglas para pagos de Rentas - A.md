## Descripción

Yo como negocio de sarlaft Quiero: 
 **** ****  **** **Ajustes en reglas del motor de riesgo para manejo por valor de pago**   
- Modificar las reglas de asignación de riesgo del motor para incluir el valor del pago como criterio de evaluación. 
- Incorporar un nuevo archivo Excel de configuración del motor, que permita gestionar las reglas basadas en el valor del pago y su interacción con las reglas actuales. 
- Ajustar la lógica para que el valor del pago impacte las demás reglas del motor cuando corresponda. 
- Adicionar soporte para los tipos passthrough y corredores dentro de la configuración y procesamiento del motor.
