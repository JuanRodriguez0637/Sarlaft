## Descripción

Como PO SARLAFT
 quiero que se cree  un pipeline automatizado para el Componente Transversal de Monitoreo de Listas,
 para permitir su primer despliegue a producción, que garantice la validación efectiva de todas las conexiones necesarias antes del despliegue, asegurando la correcta operación y continuidad del monitoreo de listas restrictivas conforme a los requerimientos del SARLAFT.

## Criterios de Aceptación

- Crear repositorio para almacenar el flujo de integración 
- Crear pipelines  de despliegue en DataFactory para DLLo, labo y PDN 
- Documentación en confluence
