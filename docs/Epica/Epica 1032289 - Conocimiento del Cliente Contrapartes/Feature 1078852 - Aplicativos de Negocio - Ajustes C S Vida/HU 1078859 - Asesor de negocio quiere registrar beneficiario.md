## Descripción

Como **asesor de negocio**

Quiero que en los cotizadores de **Plan Vive** y **Plan Crédito Protegido (PCP)** los beneficiarios solo puedan registrarse de forma estructurada

Para **evitar el ingreso como texto libre**, asegurar la **calidad de información** y cerrar brechas de auditoría SARLAFT.

## Criterios de Aceptación

- Dado que estoy cotizando un negocio nuevo en Plan Vive o PCP, cuando intento ingresar beneficiarios, entonces el sistema no debe permitir texto libre para beneficiarios. 
- Dado que el cliente cuenta con información básica del beneficiario, cuando decide registrarlo, entonces el sistema debe permitir crear el beneficiario de forma estructurada. 
- Dado que el cliente no cuenta con información del beneficiario, cuando continúa el proceso, entonces el sistema debe permitir la expedición dejando constancia de que se definirá en reclamación.
