## Descripción

Como **gestor de vida grupo**

Quiero una plantilla de carga masiva que incluya campos obligatorios (asegurados/beneficiarios) definidos en el fortalecimiento SARLAFT

Para reducir errores, reprocesos y asegurar calidad de datos para monitoreo.

## Criterios de Aceptación

- Dado que debo cargar masivamente, cuando obtengo la plantilla autorizada, entonces incluye campos SARLAFT obligatorios y están identificados. 
- Dado que proceso un archivo, cuando faltan obligatorios o hay formato inválido, entonces se rechazan registros inválidos y se informa motivo para corrección. 
- Dado que el archivo es válido, cuando se procesa, entonces queda registrado y disponible para análisis/monitoreo posterior.
