# Servicio Adicionar Evidencias

> **Fuente Confluence:** [Servicio Adicionar Evidencias](https://segurosti.atlassian.net/wiki/spaces/EPA/pages/1814003981)
> **Última modificación:** 2021-04-07 — Diana Muñoz · versión 3
> **Sección:** [Servicios Web](./index.md)
- **Objetivo:** Permite recibir las evidencias de validaciones realizadas directamente por los aplicativos de negocio y así completar las validaciones mínimas del sarlaft
- **Endpoint:** /sarlaftserv/assessment/addevidence
- **Perfil de Seus4:** PF_CONSUMSERVSARLAFTAPI
- **Ejemplo Json Request:**

[`request_assessment.json`](./ServicioAdicionarEvidencias/request_assessment.json) | [`request_addevidence.json`](./ServicioAdicionarEvidencias/request_addevidence.json)

- **Dependencias:**
  - Base de Datos Saralft
