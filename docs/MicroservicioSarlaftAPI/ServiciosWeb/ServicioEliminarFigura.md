# Servicio Eliminar Figura

**Fuente Confluence:** [Servicio Eliminar Figura](https://segurosti.atlassian.net/wiki/spaces/EPA/pages/2281078788)
**Sección:** [Servicios Web](../index.md)

---

- **Objetivo:** Permite eliminar una persona, con un rol en especifico diferente de Tomador, de un proceso de evaluación, cuando el cliente quiere hacerlo desde aplicativo front para sarlafts realizados desde cero.
- **Endpoint:** /sarlaftserv/assessment/figure/delete
- **Perfil de Seus4:** PF_CONSUMSERVSARLAFTAPI
- **Ejemplo Json Request:**

[`Request.json`](./ServicioEliminarFigura/Request.json)

- **Dependencias:**
  - Base de Datos Saralft
  - Aplicaciones Externas.
