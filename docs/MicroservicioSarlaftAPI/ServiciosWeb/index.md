## Descripción

Esta sección documenta todos los endpoints REST expuestos por el microservicio **SarlaftAPI**. Cada servicio tiene su propia subpágina con la especificación del endpoint, parámetros, perfiles de seguridad (SEUS4) y ejemplos de request/response.
