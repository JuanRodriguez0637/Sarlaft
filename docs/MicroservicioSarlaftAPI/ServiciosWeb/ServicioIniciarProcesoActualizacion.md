# Servicio Iniciar Proceso Actualización

**Fuente Confluence:** [Servicio Iniciar Proceso Actualización](https://segurosti.atlassian.net/wiki/spaces/EPA/pages/1813512457)
**Sección:** [Servicios Web](../index.md)

---

- **Objetivo:** Permite iniciar un proceso de validación y actualización del Sarlaft de un cliente para que este mismo pueda diligenciarlo directamente, atendiendo a un proceso de autogestión importante para procesos masivos de expediciones o renovaciones.
- **Endpoint:** /sarlaftserv/assessment/update
- **Perfil de Seus4:** PF_CONSUMSERVSARLAFTAPI
- **Ejemplo Json Request:**

[`request_assessment.json`](./ServicioIniciarProcesoActualizacion/request_assessment.json)

- **Dependencias:**
  - Base de Datos Saralft
